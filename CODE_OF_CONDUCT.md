# Code of conduct

## The short version

Be decent. Assume good faith. Critique code, not people.

This is a small project. It doesn't need a bureaucracy, but it does need a
clear line, so:

## Expected behaviour

- Be respectful of differing experience levels. "This is obvious" is rarely
  useful feedback.
- Give concrete, actionable review comments.
- Accept that the maintainer may decline a change. This plugin is
  deliberately minimal; "useful" is not by itself sufficient reason to add
  something.

## Unacceptable behaviour

- Harassment, personal attacks, or demeaning comments — public or private.
- Discriminatory language or imagery of any kind.
- Publishing others' private information without permission.
- Sustained disruption of discussions or deliberate bad-faith argument.

## Scope

This applies in issues, pull requests, discussions, and any other space where
you're taking part in this project.

## Enforcement

Report a problem through a
[private security advisory](https://github.com/Dhananjay625/dev-workflow/security/advisories/new)
— it is the only private channel this repo has, and it works for conduct
reports too.

Reports are handled by the maintainer. Depending on severity, the response
ranges from a warning to a block from the repository. Reports stay
confidential.
